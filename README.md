# 플라스틱 배출량 기반 과세 — 복습 서바이버

발표(PPT)가 끝난 뒤 **반 친구들이 한 명씩 나와서 직접 플레이**하며 내용을 복습하는 게임입니다.

- **1라운드만** 탕탕특공대식 서바이버(이동만, 공격 자동)
- **2~6라운드는 언더테일식 보스 탄막** — 기본 난이도는 교실에서 한 명씩 돌려도 될 정도로 여유 있습니다
- 경험치 조각은 **수초 뒤 소멸** (게이지). **⚡ 전량 흡수**로 한 번에 쓸어담는 맛이 핵심입니다
- 죽으면 **재시도(그 라운드 시작 전)** 또는 **스킵(시간 없을 때)** 을 고릅니다

빌드 도구 없이 `index.html` 하나로 동작합니다.

---

## 1. Vercel 배포

**A. 드래그 앤 드롭 (1분)**
1. 압축을 푼 폴더(`index.html`, `vercel.json`)를 준비
2. https://vercel.com/new 접속 → 폴더 업로드 영역에 **폴더째 드래그**
3. Framework **Other**, Build Command·Output Directory 비움 → Deploy

**B. Vercel CLI**
```bash
npm i -g vercel
cd plastic-tax-game
vercel            # 첫 배포 (질문은 전부 Enter, 프레임워크는 Other)
vercel --prod     # 발표용 주소로 배포
```

**C. GitHub 연동** — 폴더를 저장소에 push → Vercel에서 Import → Framework **Other**

> 정적 파일 하나뿐이라 빌드 설정이 필요 없습니다. `vercel.json`은 캐시를 끄고
> (수정 후 새로고침하면 바로 반영) 어떤 경로로 들어와도 게임이 열리도록 리라이트만 걸어 둔 파일입니다.

## 2. 진행 방식

```
"해 볼 사람?" → 손 든 사람 지목 → 라운드 클리어 → 복습 문제 → 다음 라운드
```

- **라운드 = PPT 목차 구간.** 총 **6라운드**, 22문항.
- **1라운드**만 오염 몬스터가 사방에서 몰려옵니다. 이동(WASD/방향키)만 하면 되고 공격은 자동입니다.
- 적을 잡으면 **경험치 조각**이 튀고, 조각마다 **소멸 게이지**가 돌아갑니다. 시간이 끝나면 증발합니다.
- **⚡ 전량 흡수**를 주우면 맵에 떨어진 경험치를 **한 번에** 삼킵니다 (레벨이 여러 칸 뛸 수 있음).
- **2~6라운드**는 보스전입니다. 좁은 상자 안에서 **탄막 패턴을 피하면서** 보스를 자동 공격합니다.
- 시간을 다 버티거나 보스를 잡으면 라운드 클리어 → **복습 문제** → 다음 사람 차례.
- **체력이 0이 되면** 그 자리에서 교대하지 않습니다. **재시도**(해당 라운드 시작 전으로) 또는 **스킵**(복습 문제로)을 고릅니다.
- 막히거나 시간이 없으면 오른쪽 위 **⏭ 라운드 스킵**(또는 `N`). 스킵해도 복습 문제는 그대로 나옵니다.

### 교대 규칙

- 라운드가 시작될 때마다 **"해 볼 사람?"** 화면이 뜹니다.
  손 든 사람 중에서 발표자가 골라 나오게 하세요.
  이름은 **적어도 되고 비워 둬도 됩니다**(자동으로 '도전자 1·2·3…').
- **죽으면 재시도 / 스킵**을 고릅니다. 재시도는 레벨·강화·점수를 **그 라운드에 들어가기 직전**으로 되돌립니다.

## 3. 🍪 간식 주인공 — 딜량 성장률 랭킹

참여를 끌어내기 위한 장치입니다. 차례마다 **낸 피해량과 실제 플레이 시간**을 재서
**초당 피해(DPS)** 를 뽑고, **직전 사람보다 몇 % 더 냈는지**로 순위를 매깁니다.

- **첫 주자(발표자)가 기준**이 됩니다. 그다음부터 직전 사람과 비교합니다.
- 딜량은 **실제로 몬스터 체력을 깎은 만큼만** 셉니다(오버킬 제외).
- **5초 미만**으로 끝난 차례는 순위에서 빠집니다.

## 4. 경험치 조각과 아이템

센 몬스터일수록 좋은 조각을 떨구고, 낮은 확률로 등급이 한 단계 올라갑니다.
조각은 **편하게 기준 약 12~16초 뒤 소멸**하며, 바닥에 **원형 게이지**가 줄어듭니다.

| 조각 | 색 | 경험치 | 수명 |
|---|---|---|---|
| 조각 | 하늘색 | 1 | 짧음 |
| 덩이 | 초록 | 3 | 보통 |
| 결정 | 보라 | 9 | 조금 김 |
| **황금 결정** | 금색 | **25** | 가장 김 |

특수 아이템(회복·폭탄은 드물고 약합니다).

| 아이템 | 효과 |
|---|---|
| ✚ 정화 팩 | 체력 **+14** |
| 🧲 자석 코어 | 조각을 **끌어옴** (수명은 그대로) |
| **⚡ 전량 흡수** | 맵의 경험치를 **즉시 전부 삼킴** — 도파민 아이템 |
| ☢ 충격탄 | **좁은 범위**에 중간 피해 + 넉백 (화면 전체 삭제는 없음) |

## 7. 보스전

보스는 상자 위에서 패턴을 돌립니다. 플레이어는 **상자 안에서만** 움직이며 탄을 피합니다.

- 탄·레이저·뼈 벽에 맞으면 **체력이 크게** 깎입니다 (2~3대면 위험).
- 패턴마다 예고(텔레그래프)가 잠깐 뜨고, 체력이 절반 아래로 떨어지면 패턴이 빨라집니다.
- 죽으면 **재시도**로 그 보스전 시작 전으로 돌아가거나, **스킵**으로 문제로 넘어갑니다.

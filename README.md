# 플라스틱 배출량 기반 과세 — 복습 서바이버

발표(PPT)가 끝난 뒤 **네 명이 한 명씩** 나와서 플레이하며 내용을 복습하는 게임입니다. **약 7분**을 기준으로 짜여 있습니다.

- 각 차례는 **사냥·레벨업**으로 시작하고, **끝날 때쯤 보스**가 나옵니다
- 사냥은 **쓰레기 파도**(최대 240마리)를 오라·위성·파동·폭발로 쓸어넘기는 맛입니다
- 경험치 조각은 **수초 뒤 소멸** (게이지). **⚡ 전량 흡수**로 한 번에 쓸어담습니다
- 죽으면 **한 번 부활**(체력 절반)하고, 그다음엔 **재시도** 또는 **스킵**입니다

빌드 도구 없이 `index.html` 하나로 동작합니다.

---

## 1. Vercel 배포

**A. 드래그 앤 드롭 (1분)**
1. 압축을 푼 폴더(`index.html`, `vercel.json`)를 준비
2. https://vercel.com/new 접속 → 폴더 업로드 영역에 **폴더째 드래그**
3. Framework **Other**, Build Command·Output Directory 비움 → Deploy

**B. Vercel CLI**
```bash
npm i -g vercel
cd plastic-tax-game
vercel            # 첫 배포 (질문은 전부 Enter, 프레임워크는 Other)
vercel --prod     # 발표용 주소로 배포
```

**C. GitHub 연동** — 폴더를 저장소에 push → Vercel에서 Import → Framework **Other**

> 정적 파일 하나뿐이라 빌드 설정이 필요 없습니다. `vercel.json`은 캐시를 끄고
> (수정 후 새로고침하면 바로 반영) 어떤 경로로 들어와도 게임이 열리도록 리라이트만 걸어 둔 파일입니다.

## 2. 진행 방식

```
"해 볼 사람?" → 손 든 사람 지목 → 약 38초 사냥·레벨업 → 보스 → 복습 문제 → 다음 사람
```

- **4차례 · 약 7분.** 한 명당 사냥 후 보스 한 판, 문제는 2~3문항입니다.
- 이동(WASD/방향키)만 하면 되고 공격은 자동입니다. **정화 오라·위성·파동**이 처음부터 켜져 있고, 총알은 **스플래시**, 처치 시 **연쇄 폭발**이 납니다.
- 적은 **떼로** 몰려옵니다(화면 한가득, 상한 240). 잔챙이(빨대·펠릿·비즈)는 경험치를 거의 안 줍니다.
- 적을 잡으면 **경험치 조각**이 튀고, 조각마다 **소멸 게이지**가 돌아갑니다.
- **⚡ 전량 흡수**를 주우면 맵의 경험치를 **한 번에** 삼킵니다.
- 타이머가 끝나면 **보스**가 등장합니다. 강화한 상태로 상자 안 탄막을 피합니다.
- 보스를 잡으면 **복습 문제** → 다음 사람.
- **체력이 0이 되면** 한 번 **부활(체력 절반)**. 목숨을 다 쓰면 재시도(사냥이면 그 차례 시작 전, 보스면 보스 직전) 또는 스킵(문제로).
- 막히면 오른쪽 위 **스킵**(또는 `N`). 스킵해도 복습 문제는 나옵니다.

### 교대 규칙

- 라운드가 시작될 때마다 **"해 볼 사람?"** 화면이 뜹니다.
  손 든 사람 중에서 발표자가 골라 나오게 하세요.
  이름은 **적어도 되고 비워 둬도 됩니다**(자동으로 '도전자 1·2·3…').
- **죽으면 재시도 / 스킵**을 고릅니다. 사냥 중이면 그 차례 **시작 직전**으로, 보스 중이면 **보스 직전**(레벨·강화 유지)으로 되돌립니다.

## 3. 🍪 간식 주인공 — 딜량 성장률 랭킹

참여를 끌어내기 위한 장치입니다. 차례마다 **낸 피해량과 실제 플레이 시간**을 재서
**초당 피해(DPS)** 를 뽑고, **직전 사람보다 몇 % 더 냈는지**로 순위를 매깁니다.

- **첫 주자(발표자)가 기준**이 됩니다. 그다음부터 직전 사람과 비교합니다.
- 딜량은 **실제로 몬스터 체력을 깎은 만큼만** 셉니다(오버킬 제외).
- **5초 미만**으로 끝난 차례는 순위에서 빠집니다.

## 4. 경험치 조각과 아이템

센 몬스터일수록 좋은 조각을 떨구고, 낮은 확률로 등급이 한 단계 올라갑니다.
조각은 **편하게 기준 약 12~16초 뒤 소멸**하며, 바닥에 **원형 게이지**가 줄어듭니다.

| 조각 | 색 | 경험치 | 수명 |
|---|---|---|---|
| 조각 | 하늘색 | 1 | 짧음 |
| 덩이 | 초록 | 3 | 보통 |
| 결정 | 보라 | 9 | 조금 김 |
| **황금 결정** | 금색 | **25** | 가장 김 |

특수 아이템(회복·폭탄은 드물고 약합니다).

| 아이템 | 효과 |
|---|---|
| ✚ 정화 팩 | 체력 **+8** |
| 🧲 자석 코어 | 조각을 **끌어옴** (수명은 그대로) |
| **⚡ 전량 흡수** | 맵의 경험치를 **즉시 전부 삼킴** — 도파민 아이템 |
| ☢ 충격탄 | **넓은 범위**에 중간 피해 + 넉백 |
| **🎁 보물상자** | 보스 처치 시 등장. **레벨 +3~4** + 강화 연속 선택 |

## 6. 라운드 구성 (4명 · 약 7분)

각 차례는 **사냥 38초 → 보스 → 퀴즈 2~3문항**입니다.

| 차례 | 사냥 | 보스 | 내용 | 퀴즈 |
|---|---|---|---|---|
| 1 | 빨대·펠릿·뚜껑·봉지·컵·미세플라스틱 | 오염자 부담 | 플라스틱세란? | q101, q201, q202 |
| 2 | +비즈·마스크·과대포장·페트병 드론 | 재생원료 장벽 | 업스트림(영국·EU) | q301, q402 |
| 3 | +테이프·스티로폼·기름때·그물 | 배출 압박 | 다운스트림 | q501, q602, q502 |
| 4 | 전부(+폐타이어·수출 상자) | 플라스틱 덩어리 | 쟁점·찬반 정리 | q801, q901, q1003 |

### 적 종류

| 종류 | 역할 |
|---|---|
| 빨대 · 펠릿 · 마이크로비즈 | 잔챙이 떼. 체력 낮고 많이 나옴 |
| 페트 뚜껑 · 봉지 · 컵 · 마스크 · 테이프 | 기본 잡몹 |
| 과대포장 · 페트병 드론 · 스티로폼 · 미세플라스틱 · 기름때 | 중간 |
| 유령그물 · 폐타이어 · 수출 상자 | 탱크 |
| 플라스틱 덩어리 | 보스 |

문항은 짧고, 보기 순서는 매번 섞입니다. 나머지 문항은 `QUIZ_BANK`에 남아 있어 필요하면 `ROUNDS`의 `qs`에 넣으면 됩니다.

## 7. 보스전

사냥이 끝나면 보스가 상자 위에서 패턴을 돌립니다. 플레이어는 **상자 안에서만** 움직이며 탄을 피합니다. 사냥에서 얻은 강화는 그대로입니다.

- 맞으면 체력이 깎입니다. 기본은 **보통**(예전 난이도의 약 95%)입니다.
- 패턴마다 예고가 잠깐 뜨고, 체력이 절반 아래로 떨어지면 패턴이 빨라집니다.
- 보스를 잡으면 **보물상자**가 떨어집니다. 열면 레벨이 한꺼번에 오르고 강화를 고릅니다.
- 사냥 중에 죽으면 그 차례 **시작 전**으로, 보스에서 죽으면 **보스 직전**(레벨·강화 유지)으로 재시도합니다.

## 9. 난이도

기본값은 **보통**입니다. 예전 난이도의 약 95%입니다.

| | 편하게 | 보통 | 빡세게 |
|---|---|---|---|
| 적 체력 | ×0.95 | ×1.19 | ×1.47 |
| 받는 피해 | ×0.95 | ×1.38 | ×1.71 |
| 적 이동 속도 | ×0.95 | ×1.03 | ×1.12 |
| 스폰 | 조금 여유 | 촘촘 | 더 촘촘 |
| 정화 팩 | 가끔 | 드묾 | 거의 없음 |
| 조각 수명 | 8.4초 | 6.8초 | 5.3초 |
| 보스 체력 | ×0.95 | ×1.28 | ×1.61 |

보스를 잡으면 **보물상자**가 떨어집니다. 열면 레벨이 3~4 오르고 강화를 연속으로 고릅니다.

복습 문제는 보기 순서가 **매번 섞입니다.**

## 10. 문제 수정하기

`index.html` 위쪽 **`QUIZ_BANK`** 만 고치면 됩니다. 배치는 **`ROUNDS`** 의 `qs` 배열입니다.

```js
{ n:2, title:'업스트림', sub:'…',
  qs:['q301','q402'], bossId:1, pool:['bag','cup','bottle'], theme:{ … } }
```

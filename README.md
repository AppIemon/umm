# 플라스틱 배출량 기반 과세 — 복습 서바이버

발표(PPT)가 끝난 뒤 **바로 이어서** 플레이하는 교실 복습 게임입니다. **약 7분**, 네 차례입니다.

- **1라운드는 발표자 시범.** 그다음 손 든 세 명이 이어서 합니다
- 각 차례는 **사냥·레벨업 → 보스 → 방금 들은 내용 퀴즈**
- 퀴즈는 **틀려도 강화 1회**, **맞히면 강화 2회**
- 🍪 **오레오 1등** = 직전 사람 대비 DPS 성장률 1위 (발표자 시범이 기준선)
- 시작 시 세 곡 중 **랜덤 BGM**. `M` 으로 끄고 켭니다

빌드 없이 `index.html` + `music/` 로 동작합니다. 발표용 슬라이드는 `플라스틱세.pptx` 입니다.

---

## 1. Vercel 배포

**A. 드래그 앤 드롭 (1분)**
1. 압축을 푼 폴더(`index.html`, `vercel.json`, `music/`)를 준비
2. https://vercel.com/new 접속 → 폴더 업로드 영역에 **폴더째 드래그**
3. Framework **Other**, Build Command·Output Directory 비움 → Deploy

**B. Vercel CLI**
```bash
npm i -g vercel
cd plastic-tax-game
vercel            # 첫 배포 (질문은 전부 Enter, 프레임워크는 Other)
vercel --prod     # 발표용 주소로 배포
```

**C. GitHub 연동** — 폴더를 저장소에 push → Vercel에서 Import → Framework **Other**

> 정적 파일이라 빌드 설정이 필요 없습니다. `vercel.json`은 캐시를 끕니다
> (수정 후 새로고침하면 바로 반영). BGM은 `music/1.mp3` · `2.mp3` · `3.mp3` 입니다.

## 2. 진행 방식

```
PPT 끝 → 링크 열고 1R 시범 → 손 든 사람 지목 → 38초 사냥 → 보스 → 퀴즈(강화) → 다음
```

- **4차례 · 약 7분.** 한 명당 사냥 후 보스 한 판, 문제는 3문항입니다.
- **1라운드**는 이름칸이 `발표자`로 채워진 시범 화면이 뜹니다.
- 이동(WASD/방향키)만 하면 되고 공격은 자동입니다.
- 퀴즈를 **틀려도 강화 1장**, **맞히면 2장**입니다. 의견 문항은 1장입니다.
- 타이머가 끝나면 **보스**. 잡은 뒤 **보물상자**(레벨 +3~4) → 복습 문제.
- **체력이 0이 되면** 재시도(사냥이면 그 차례 시작 전, 보스면 보스 직전) 또는 스킵.
- 막히면 오른쪽 위 **스킵**(또는 `N`). 스킵해도 복습 문제는 나옵니다.
- 시작 시 BGM이 세 곡 중 하나 랜덤으로 돕니다. `M` 으로 음소거.

### 교대 규칙

- 2~4라운드가 시작될 때마다 **"해 볼 사람?"** 화면이 뜹니다.
  손 든 사람 중에서 발표자가 골라 나오게 하세요.
  이름은 **적어도 되고 비워 둬도 됩니다**(자동으로 '도전자 1·2·3…').
- **죽으면 재시도 / 스킵**을 고릅니다. 사냥 중이면 그 차례 **시작 직전**으로, 보스 중이면 **보스 직전**(레벨·강화 유지)으로 되돌립니다.

## 3. 🍪 오레오 1등 — 직전 대비 DPS

참여를 끌어내기 위한 장치입니다. **총딜 1등이 아닙니다.**
차례마다 **낸 피해량과 실제 플레이 시간**을 재서 **초당 피해(DPS)** 를 뽑고,
**직전 사람보다 몇 % 더 냈는지**로 순위를 매깁니다.

- **1라운드 발표자 시범이 기준선**입니다. 발표자는 오레오 후보가 아닙니다.
- 그다음 사람부터 직전 차례와 비교합니다. 뒤 사람이 이길 여지가 있습니다.
- 딜량은 **실제로 몬스터 체력을 깎은 만큼만** 셉니다(오버킬 제외).
- **5초 미만**으로 끝난 차례는 순위에서 빠집니다.
- 게임이 끝나면 결과 화면에 **🍪 오레오 1등**이 크게 나옵니다.

## 4. 경험치 조각과 아이템

센 몬스터일수록 좋은 조각을 떨구고, 낮은 확률로 등급이 한 단계 올라갑니다.
조각은 **편하게 기준 약 12~16초 뒤 소멸**하며, 바닥에 **원형 게이지**가 줄어듭니다.

| 조각 | 색 | 경험치 | 수명 |
|---|---|---|---|
| 조각 | 하늘색 | 1 | 짧음 |
| 덩이 | 초록 | 3 | 보통 |
| 결정 | 보라 | 9 | 조금 김 |
| **황금 결정** | 금색 | **25** | 가장 김 |

특수 아이템(회복·폭탄은 드물고 약합니다).

| 아이템 | 효과 |
|---|---|
| ✚ 정화 팩 | 체력 **+8** |
| 🧲 자석 코어 | 조각을 **끌어옴** (수명은 그대로) |
| **⚡ 전량 흡수** | 맵의 경험치를 **즉시 전부 삼킴** — 도파민 아이템 |
| ☢ 충격탄 | **좁은 범위**에 중간 피해 + 넉백 (화면 전체 삭제는 없음) |
| **🎁 보물상자** | 보스 처치 시 등장. **레벨 +3~4** + 강화 연속 선택 |

## 6. 라운드 구성 (4명 · 약 7분)

각 차례는 **사냥 38초 → 보스 → 퀴즈 2~3문항**입니다.

| 차례 | 누가 | 사냥 | 내용 | 퀴즈 |
|---|---|---|---|---|
| 1 시범 | 발표자 | 봉지·컵·미세플라스틱 | 정의 · 오염자 부담 | 쓰거나 버린 양 / 오염자 부담 / 업·다운스트림 |
| 2 | 손 든 사람 | +페트병 드론 | 업스트림 (영국 PPT · EU) | 재생원료 30% / 생산자·수입자 / 회원국 0.80유로 |
| 3 | 손 든 사람 | +스티로폼·그물 | 다운스트림 (종량제·보증금) | 종량제 / 한국 사례 / 보증금 환급 |
| 4 | 손 든 사람 | 전부 | 공평성 · 찬반 | 역진세 / 찬성 논거 / 의견 |

문항은 PPT와 맞춰 두었고, 보기 순서는 매번 섞입니다. 나머지 문항은 `QUIZ_BANK`에 남아 있습니다.

## 7. 보스전

사냥이 끝나면 보스가 상자 위에서 패턴을 돌립니다. 플레이어는 **상자 안에서만** 움직이며 탄을 피합니다. 사냥에서 얻은 강화는 그대로입니다.

- 맞으면 체력이 깎입니다. 기본은 **보통**(예전 난이도의 약 95%)입니다.
- 패턴마다 예고가 잠깐 뜨고, 체력이 절반 아래로 떨어지면 패턴이 빨라집니다.
- 보스를 잡으면 **보물상자**가 떨어집니다. 열면 레벨이 한꺼번에 오르고 강화를 고릅니다.
- 사냥 중에 죽으면 그 차례 **시작 전**으로, 보스에서 죽으면 **보스 직전**(레벨·강화 유지)으로 재시도합니다.

## 8. 강화 카드

레벨업 때와 **퀴즈마다** 3택1입니다. 오답 1회, 정답 2회, 의견 1회. 회복 계열은 약합니다.

| 계열 | 강화 | 효과 | 최대 |
|---|---|---|---|
| 무기 | ⚡ 연사 강화 | 공격 속도 +22% | 5 |
| 무기 | ✳ 분열 광선 | 광선이 한 갈래 늘어남 | 4 |
| 무기 | 💥 고출력 탄두 | 광선 피해 +2 | 5 |
| 무기 | ➤ 관통 코팅 | 적을 한 명 더 뚫고 지나감 | 3 |
| 무기 | ≫ 장거리 조준 | 사거리 +25%, 탄속 +20% | 3 |
| 특수 | 🛰 분해 위성 | 주위를 도는 위성이 적을 타격 | 4 |
| 특수 | 🌀 정화 오라 | 내 주변 적에게 지속 피해 | 4 |
| 특수 | ☢ 연쇄 분해 | 처치 시 주변 적에게 폭발 피해 | 3 |
| 체력 | ❤ 강화 체질 | 최대 체력 +18 (소량 회복) | 5 |
| 체력 | ✚ 자가 정화 | 4초마다 체력 +2 회복 | 4 |
| 체력 | 🜂 분해 흡수 | 적 처치 시 체력 +1 | 4 |
| 체력 | ✦ 응급 정화 | 지금 체력의 35%를 회복 | 제한 없음 |
| 방어 | 🛡 방어구 코팅 | 받는 피해 18% 감소 | 4 |
| 방어 | ⏳ 무적 시간 + | 피격 후 무적 시간 +50% | 2 |
| 이동 | 👟 경량화 부츠 | 이동 속도 +14% | 4 |
| 이동 | 🧲 자석 코일 | 경험치 조각 수집 범위 +60% | 3 |

## 9. 난이도

기본값은 **보통**입니다. 예전 난이도의 약 95%입니다.

| | 편하게 | 보통 | 빡세게 |
|---|---|---|---|
| 적 체력 | ×0.95 | ×1.19 | ×1.47 |
| 받는 피해 | ×0.95 | ×1.38 | ×1.71 |
| 적 이동 속도 | ×0.95 | ×1.03 | ×1.12 |
| 스폰 | 조금 여유 | 촘촘 | 더 촘촘 |
| 정화 팩 | 가끔 | 드묾 | 거의 없음 |
| 조각 수명 | 8.4초 | 6.8초 | 5.3초 |
| 보스 체력 | ×0.95 | ×1.28 | ×1.61 |

보스를 잡으면 **보물상자**가 떨어집니다. 열면 레벨이 3~4 오르고 강화를 연속으로 고릅니다.

복습 문제는 보기 순서가 **매번 섞입니다.**
